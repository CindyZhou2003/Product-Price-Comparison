# 商品比价网站测试报告

## 测试概述

本测试报告基于 B/S 体系软件设计课程中完成的课程项目《商品比价网站》进行

### 测试目的

- 确保商品比价网站的各项功能符合需求规格说明书的要求。
- 发现系统缺陷，保证网站稳定性、可用性和安全性。
- 验证系统的性能和兼容性，确保用户体验良好。

### 测试对象

测试内容包括以下核心功能：

1. **用户注册与登录**
2. **商品查询与比价**
3. **历史价格查询**
4. **降价提醒**
5. **个人中心与设置**
6. **移动端适配**

### 测试环境

|      | 硬件配置                |          | 软件配置                              |
| ---- | ----------------------- | -------- | ------------------------------------- |
| CPU  | Intel i7-1355U 1.70 GHz | 操作系统 | Windows 11 / Android 11 / iOS 15      |
| 内存 | 32GB                    | 浏览器   | Chrome 100.0, Firefox 96.0, Safari 15 |
| 硬盘 | 1TB SSD                 | 数据库   | MySQL 8.0                             |

- 网络环境：校园网


### 测试工具

- **功能测试**：手工测试 + Selenium 自动化工具
- **性能测试**：JMeter
- **缺陷管理**：禅道、Jira
- **浏览器兼容性测试**：Chrome DevTools

## 测试过程与结果

### 功能测试结果

功能测试涵盖了注册、登录、商品查询、历史价格、降价提醒等功能，测试结果如下：

| **测试功能**     | **测试用例数** | **通过用例数** | **失败用例数** | **通过率** |
| ---------------- | -------------- | -------------- | -------------- | ---------- |
| 用户注册与登录   | 4              | 4              | 0              | 100%       |
| 商品查询与比价   | 2              | 2              | 0              | 100%       |
| 历史价格查询     | 1              | 1              | 0              | 100%       |
| 降价提醒         | 1              | 1              | 0              | 100%       |
| 浏览器兼容性测试 | 1              | 1              | 0              | 100%       |
| 移动端适配       | 1              | 1              | 0              | 100%       |

**功能测试结果总结**：所有测试用例均通过，网站功能满足需求。

### 性能测试结果

通过 JMeter 对网站进行性能测试，结果如下：

- **并发用户数**：100 个并发用户
- **响应时间**：平均响应时间 1.2 秒
- **系统吞吐量**：200 请求/秒
- **错误率**：0%

**性能测试结果总结**：网站性能稳定，满足高并发访问的需求。

### 浏览器兼容性测试结果

在主流浏览器（Chrome、Firefox、Safari）上测试网站兼容性：

- 页面布局正常，无错位现象。
- 功能操作正常，未出现异常。

| **缺陷级别** | **缺陷数量** | **已修复** | **未修复** |

| 严重         | 0            | 0          | 0          |
| 一般         | 2            | 2          | 0          |
| 轻微         | 3            | 3          | 0          |

**缺陷总结**：所有已发现的缺陷均已修复，系统整体质量较好。

## 测试结论

经过全面测试，商品比价网站具有以下特点：

1. 功能完整，符合需求规格说明书的要求。
2. 性能稳定，支持高并发访问。
3. 兼容主流浏览器，适配移动端设备。
4. 系统缺陷已修复，整体质量较高。

**测试结论**：商品比价网站通过测试，可初步部署上线。
