# 商品比价网站-开发心得

[TOC]

## 开发心得

经过数月的努力，商品比价网站从构想到落地的全过程为我提供了一次全面的学习和实践机会。在开发和部署的过程中，我积累了许多宝贵的经验，也遇到了许多挑战，以下是我在此次项目开发中的心得总结。

### **技术选型的思考**

在技术选型阶段，我选择了前端使用 **React.js**，后端使用 **Django**，并通过 **MySQL** 数据库管理数据。这些技术各有特点，能很好地协同工作：

- **React.js** 提供了高效的组件化开发模式，使得前端页面的功能模块化和逻辑清晰。
- **Django** 是一个全功能框架，内置了强大的 ORM，能快速实现后端接口和数据库交互。
- **MySQL** 则以其高效的存储和查询能力，为系统的核心数据管理提供了稳定的支持。

此外，爬虫部分选择 **DrissionPage** 和 **Selenium**，不仅能满足多平台数据抓取需求，还能应对一些电商平台的反爬机制。

### **主要的开发挑战及应对方法**

1. **跨平台数据抓取的复杂性**
   - 不同电商平台的数据结构和反爬机制不同。在开发过程中，爬虫需要针对每个平台进行单独设计，提升爬虫的稳定性。
   - 使用 **Selenium** 模拟用户操作时，遇到了性能瓶颈。为了解决这个问题，我优化了爬虫的任务调度策略，减少不必要的操作，提高了抓取效率。
2. **前后端数据交互**
   - 数据交互过程中，遇到了跨域请求的问题，通过配置 Django 的 CORS 中间件成功解决。
3. **历史价格展示**
   - 在实现历史价格的图表展示功能时，前端使用 **Chart.js**，但初始数据量较大时导致渲染速度较慢。通过前端数据分页加载和后端查询优化，有效提升了页面的响应速度。
4. **系统性能与安全性**
   - 针对高并发查询的场景，我优化了数据库的索引设计，并对关键 API 添加了缓存机制。
   - 为了防止 SQL 注入、XSS 等安全风险，我严格过滤了用户输入，并开启了 Django 的内置 CSRF 防护。

### **收获与感悟**

1. **技术选型的合理性**
   - 此次项目让我深刻感受到技术选型对项目成败的影响。React 和 Django 的组合，让开发体验和系统性能都达到了预期。
2. **对部署与运维的深入理解**
   - 使用 **Docker** 容器化后，部署过程变得高效且可靠，但是 **Docker** 中无法实现爬虫，这一点困扰了我很久，也许以后可以采用服务器部署。
3. **用户体验的重要性**
   - 从用户角度审视功能的设计与实现，是提升产品质量的关键。例如，历史价格的图表展示，通过简洁的界面和直观的数据呈现，提升了用户体验。

### **改进之处**

尽管项目已经初步完成，但仍有许多优化空间：

1. 增加管理员模块的网页，实现远程操作，包括爬取数据、发送邮件等
2. 在服务器上部署，以实现多用户访问，实现完整的功能
3. 前端界面优化，更符合用户需求

## **总结**

本次项目不仅锻炼了我的技术能力，也让我对从需求分析到系统部署的全流程开发有了更深刻的理解。通过不断地学习和实践，我的开发思维和问题解决能力得到了极大提升，这为我未来的项目开发奠定了坚实的基础。
