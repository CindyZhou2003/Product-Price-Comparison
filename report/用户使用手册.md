# 商品比价网站-用户使用手册

**目录**

[TOC]

## 1. 简介

### 1.1 关于本网站

本网站是一款在线商品比价工具，旨在帮助用户快速查询和比较多个电商平台的商品价格，提供历史价格走势查询、降价提醒等功能，提升用户的购物决策效率。

### 1.2 适用人群

适合有比价需求的消费者，尤其是经常在线购物的用户。

## 2. 网站访问与登录

### 2.1 访问网站

- 使用浏览器输入网站地址，进入首页。
- 支持电脑端与移动端访问。

### 2.2 用户注册

1. 点击页面右上角的 **“注册”** 按钮。
2. 填写必要信息：用户名、密码、电子邮箱等。
3. 提交后，系统发送一封验证邮件，点击邮件中的链接完成注册。

### 2.3 用户登录

1. 点击页面右上角的 **“登录”** 按钮。
2. 输入已注册的用户名和密码，点击登录即可。
3. 忘记密码时，可以通过邮箱找回密码。

## 3. 核心功能操作指南

### 3.1 商品查询与比价

1. 在网站首页的搜索框中输入商品名称或关键词。
2. 点击 **“搜索”** 按钮。
3. 系统会自动从各大电商平台抓取商品信息，展示以下内容：
   - 各平台的实时价格列表。
   - 商品图片与链接，点击即可跳转至电商平台购买页面。
4. 用户可以通过排序功能查看最低价格或按平台筛选价格信息。

### 3.2 历史价格查询

1. 在搜索结果页面，选择需要查看历史价格的商品。
2. 点击 **“历史价格”** 选项卡。
3. 系统会展示商品的价格走势图，图表包含：
   - 时间轴（天、周、月）。
   - 价格变化趋势线。
4. 用户可通过图表了解商品的价格变化情况。

### 3.3 降价提醒

1. 在商品详情或搜索结果页面，点击 **“设置降价提醒”** 按钮。
2. 输入目标价格（用户希望的价格）。
3. 确认并保存。
4. 当商品价格低于设定值时，系统会通过以下方式通知用户：
   - 邮件提醒。
   - App 推送（如支持）。



### 3.4 个人中心与设置

1. **访问个人中心**：登录后，点击页面右上角的用户名，进入个人中心。
2. 管理关注商品：
   - 用户可以查看已关注的商品列表。
   - 删除或更新降价提醒设置。
3. 账号设置：
   - 修改密码、邮箱等个人信息。
   - 退出登录。

## 4. 移动端访问与支持

- 打开手机浏览器，访问网站地址。
- 界面自适应手机屏幕，方便操作。
- （可选）用户可下载移动应用程序（如后续开发）以获取更快捷的服务。

## 5. 常见问题（FAQ）

### Q1：如何找回密码？

在登录界面点击 **“忘记密码”**，根据提示通过邮箱找回密码。

### Q2：降价提醒的通知方式有哪些？

目前支持邮件通知，后续将支持 App 推送。

### Q3：历史价格数据多久更新一次？

系统每天定时抓取并更新商品价格数据。

## 7. 附录

### 7.1 术语解释

- **比价**：比较不同电商平台的商品价格。
- **降价提醒**：当商品价格低于用户设定值时，发送提醒通知。
- **历史价格趋势**：一段时间内商品价格的变化图表。
